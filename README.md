A make.fun bounty entry for **The Printer Finally Answers** ($2): one line, in the office printer's own voice, as its comeback to the paper jams, the cryptic error codes and the thumps.

## The entry

> Error 41: jam on page 3 of 47. I've fed this office 12,847 sheets since 2019 without a single thank-you — thump me once more and I'll print your search history in color, double-sided.

## How it works

`main.ts` (Node 22, standard library only, deterministic) writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` — 1 to 240 characters, one read, no setup, no second sentence. Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
